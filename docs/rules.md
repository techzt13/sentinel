# Rules — Non-negotiable

- **Only ever target networks, devices, cards, and remotes I own.**
- Deauth/jamming against anything I don't own = illegal radio interference.
- Captive portals that collect other people's credentials = crime.
- No keyloggers or BadUSB payloads on anyone else's machine — unauthorized access + interception offenses.
- No attack features at school, work, cafés, hackathon venues, or in public.
- Owning/carrying the device is fine; **using** offensive features off my own lab network is the legal line.
- Sub-GHz: stay in the 433 MHz ISM band (correct for Hong Kong); receive/scan is fine, transmit only to my own devices.
